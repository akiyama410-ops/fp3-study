# FP3級 学習ノート

FP3級の勉強用の、自分専用の学習アプリです。iPhoneのホーム画面に追加して使えます。

## できること

- NotebookLMで作った**音声・動画・スライド**と、**教材（19個）**をまとめて見られる
- 「この端末に保存」で、**電波がない場所でも**音声や教材が使える
- **○×問題・三択問題（380問）**を解いて、正解率や「まちがえた問題」を記録
- **模擬試験**：本番形式（60問・90分）とミニ模試（20問・30分）。時間切れで自動採点、途中から再開できる
- **聞き流し**：全部・分野ごとに音声を続けて再生（ランダム、くり返し、スリープタイマー、音量バー※パソコンのみ）
- 勉強した日のカレンダー、合計の勉強時間、試験日までの計画
- 記録は保管庫（Supabase）に保存されるので、**iPhoneとパソコンで同じ記録**が見られる

## しくみ

| 部分 | 置き場所 |
|---|---|
| アプリのプログラム（このリポジトリ） | GitHub Pages で公開 |
| 教材・問題・音声などのファイル・学習記録 | Supabase（ログインした本人しか見られない） |

教材の中身や音声は、このリポジトリには入れません（公開されないようにするため）。

## はじめての設定

### 1. 保管庫（Supabase）の準備

1. Supabase の `fp3-study` プロジェクトを開く
2. 左のメニューの **SQL Editor** を開き、[`supabase/schema.sql`](supabase/schema.sql) の中身を全部貼り付けて **Run**
3. **Authentication → URL Configuration** の **Site URL** を `https://akiyama410-ops.github.io/fp3-study/` にする
4. 同じ画面の **Redirect URLs** に `https://akiyama410-ops.github.io/fp3-study/**` を追加する

ログインは、メールに届く「Sign in」リンクで行います。

- パソコンやSafariで開いているとき：リンクを押すだけ
- iPhoneのホーム画面に追加したアプリ：リンクを長押しして「リンクをコピー」し、ログイン画面に貼り付ける（ホーム画面のアプリとSafariは別々に動くため）

無料プランの標準メールは1時間に数通までしか送れません。

### 1-2. 三択問題と模擬試験のための追加の設定（1回だけ）

SQL Editor で [`supabase/002_choice_and_exams.sql`](supabase/002_choice_and_exams.sql) の中身を貼り付けて **Run**。そのあと「管理」で、三択問題入りの教材データ（`fp3-seed-v2.json`）を取り込みます。

### 2. アプリの公開（GitHub Pages）

1. このリポジトリの **Settings → Pages** を開く
2. **Source** を **GitHub Actions** にする
3. `main` ブランチに変更が入ると、自動で公開されます（Actions タブで進み具合が見られます）

公開先：`https://akiyama410-ops.github.io/fp3-study/`

### 3. ログインと教材の取り込み

1. パソコンで公開先を開き、メールアドレスでログイン（メールに届くコードを入れる）
2. 1回ログインできたら、Supabase の **Authentication → Sign In / Providers** で **Allow new users to sign up** をオフにする（他の人が登録できないようにするため）
3. 「管理」→「教材データ」で `fp3-seed.json` を取り込む
4. 「管理」→「ファイルのアップロード」で、教材ごとに音声・動画・スライドをアップロード

### 4. iPhoneで使う

1. Safariで公開先を開いてログイン
2. 共有ボタン →「ホーム画面に追加」
3. 「管理」→「まとめてこの端末に保存」で、電波なしでも使えるようにする

## 教材データ（fp3-seed.json）の作り方

```
python3 tools/build_seed.py <教材HTMLのフォルダ> fp3-seed.json
```

できたファイルは教材の中身を含むので、リポジトリには入れません（`.gitignore` で除外）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` / `css/app.css` | 画面のもと・見た目 |
| `js/app.js` | 画面（ホーム・教材・問題・記録・計画・管理） |
| `js/data.js` | 保管庫との同期、端末への保存 |
| `js/player.js` | 聞き流しプレイヤー（画面を切り替えても再生を続ける） |
| `js/stats.js` | 進み具合・正解率・計画の計算 |
| `js/store.js` | 端末の中の保存場所（IndexedDB） |
| `js/config.js` | 保管庫の接続先（公開してよい鍵だけ） |
| `sw.js` | 電波なしでもアプリを開けるようにする仕組み |
| `vendor/` | 使っているライブラリ（supabase-js 2.110.0、pdf.js 3.11.174） |
| `supabase/schema.sql` | 保管庫の初期設定 |

アプリを更新したときは、`sw.js` の `VERSION` を上げると、端末に新しい版が届きやすくなります。
